# Day 01 - Linux Basics

## 📖 Kya seekha
- Linux file system structure (/, /home, /etc, /var, /bin, etc.)
- Basic navigation commands
- Difference between absolute and relative paths

## 💻 Commands jo try kiye
```bash
pwd                 # current directory dikhata hai
ls                   # files/folders list karta hai
ls -la                # hidden files sahit detailed list
cd /path/to/dir        # directory change karta hai
mkdir new-folder        # naya folder banata hai
touch file.txt            # nayi empty file banata hai
rm file.txt                # file delete karta hai
rmdir empty-folder           # empty folder delete karta hai
cp source dest                # copy karta hai
mv source dest                  # move/rename karta hai
```

## 🎯 Challenge jo face kiya
- Absolute vs relative path samajhne mein thoda confusion hua, practice se clear hua

## 📝 Key Takeaways
- Linux mein "everything is a file"
- Root directory `/` se sab kuch start hota hai
- `man <command>` se kisi bhi command ka manual dekh sakte hain

## 🔜 Kal kya seekhunga
- File permissions (chmod, chown)
- Users and groups basics
