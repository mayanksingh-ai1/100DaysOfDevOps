# 📋 Full 100-Day Roadmap

## Phase 1: Foundations (Day 1-20)

### Linux & Command Line (Day 1-8)
- Day 1-2: Linux basics, file system structure, basic commands
- Day 3-4: File permissions, users/groups, chmod/chown
- Day 5-6: Process management, systemctl, services
- Day 7-8: Bash scripting basics (variables, loops, conditionals)

### Networking Basics (Day 9-14)
- Day 9-10: OSI model, TCP/IP basics
- Day 11-12: DNS, HTTP/HTTPS, ports
- Day 13-14: SSH, firewalls, basic security concepts

### Git & GitHub Advanced (Day 15-20)
- Day 15-16: Git branching strategies, merge vs rebase
- Day 17-18: GitHub workflows, pull requests, code review basics
- Day 19-20: Git hooks, .gitignore best practices, project practice

## Phase 2: Core DevOps Tools (Day 21-45)

### Docker (Day 21-32)
- Day 21-23: Docker basics, images vs containers
- Day 24-26: Dockerfile writing, building custom images
- Day 27-29: Docker Compose, multi-container apps
- Day 30-32: Docker networking, volumes, mini project

### CI/CD with GitHub Actions (Day 33-45)
- Day 33-35: CI/CD concepts, YAML basics
- Day 36-38: GitHub Actions — first pipeline (build & test)
- Day 39-41: Auto-deployment pipeline
- Day 42-45: Multi-stage pipelines, secrets management, mini project

## Phase 3: Orchestration & Cloud (Day 46-75)

### Kubernetes (Day 46-62)
- Day 46-49: K8s architecture, pods, nodes, clusters
- Day 50-53: Deployments, services, ConfigMaps, Secrets
- Day 54-57: Minikube setup, deploying apps locally
- Day 58-62: Ingress, scaling, mini project

### Cloud Basics — AWS (Day 63-75)
- Day 63-65: AWS fundamentals, IAM, EC2
- Day 66-68: S3, VPC basics
- Day 69-71: Load balancers, auto-scaling basics
- Day 72-75: Deploy a full app on AWS EC2, mini project

## Phase 4: Infrastructure as Code & Monitoring (Day 76-100)

### Terraform (Day 76-88)
- Day 76-79: Terraform basics, providers, resources
- Day 80-83: Variables, state management
- Day 84-88: Modules, mini project

### Monitoring & Final Projects (Day 89-100)
- Day 89-92: Prometheus + Grafana basics
- Day 93-95: Logging basics (ELK stack intro)
- Day 96-100: **Capstone Project** — Code → Docker → CI/CD → K8s → Monitoring
