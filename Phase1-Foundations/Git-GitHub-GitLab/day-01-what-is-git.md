# Day 01 - What is Git

## 📖 Kya seekha
- Git ek **version control system (VCS)** hai — code ke changes track karta hai
- Git **local** tool hai (computer pe install hota hai), internet ki zaroorat nahi
- Version control se purane versions pe wapas ja sakte hain aur multiple log saath kaam kar sakte hain

## 💻 Commands/concepts jo try kiye
```bash
git --version        # git installed hai ya nahi check karta hai
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git init              # naya git repository initialize karta hai
```

## 🎯 Challenge jo face kiya
- Samajhna tha ki Git aur GitHub alag cheezein hain — Git tool hai, GitHub uska hosting platform hai

## 📝 Key Takeaways
- Git ek **distributed** version control system hai (har developer ke paas poori history hoti hai)
- `git init` se koi bhi folder git repository ban jata hai

## 🔜 Kal kya seekhunga
- Core Git commands (add, commit, status, log)
